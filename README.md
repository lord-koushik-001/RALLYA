# 🌍 RALLYA

### Discover. Experience. Rally Together.

**RALLYA** is an all-in-one event discovery and travel platform designed to help people discover, explore, and experience exciting events and destinations around the world.

From adrenaline-fueled sporting events and music festivals to adventure experiences, cultural celebrations, and travel destinations, RALLYA brings everything together in one immersive and interactive platform.

Our goal is to make discovering your next adventure simple, engaging, and unforgettable.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/rallya.git
cd rallya
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 4. Start the Backend

```bash
npm run dev
```

### 5. Start the Frontend

In a separate terminal:

```bash
cd frontend
npm run dev
```

Open the local development URL shown in your terminal.
